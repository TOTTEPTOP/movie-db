# Каталог фильмов (Movie DB)

Веб-приложение для хранения каталога фильмов с возможностью добавления в избранное. Реализована регистрация и авторизация пользователей, фильтрация по жанрам и сортировка по рейтингу. Основной акцент сделан на проектировании базы данных SQLite.

## Стек
- Python 3, Flask
- SQLite
- HTML, CSS

## Структура базы данных
- `users` — учётные записи пользователей
- `movies` — каталог фильмов
- `favorites` — связь «многие-ко-многим» между пользователями и фильмами

Схема БД описана в файле `schema.sql`.

## Как запустить локально
1. pip install -r requirements.txt
2. python app.py
3. Открыть http://127.0.0.1:5000

## Функции
- Регистрация и вход
- Каталог фильмов
- Добавление фильмов в избранное
- Просмотр только избранных фильмов
