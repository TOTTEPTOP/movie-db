# Каталог фильмов (Movie DB)

Веб-приложение для хранения каталога фильмов с возможностью добавления в избранное. Реализована регистрация и авторизация пользователей, фильтрация по жанру и сортировка по рейтингу, году или названию.

## Стек
- Python 3, Flask
- SQLite
- HTML, CSS

## Как запустить
1. pip install flask
2. python app.py
3. Открыть http://127.0.0.1:5000

## Функции
- Регистрация и вход
- Каталог фильмов с фильтрацией по жанру
- Сортировка по рейтингу / году / названию
- Добавление фильмов в избранное
- Просмотр списка избранного
